# Support

For engineering handoff questions, start with [docs/README.md](docs/README.md) and the [dependency register](docs/handoff/dependencies-and-release-gates.md). Report reproducible defects with the repository bug template once the remote exists.

The product must provide /support and /contact, an authenticated support-request flow, request reference numbers, published coverage hours, billing assistance, moderation appeals, and an urgent account/privacy route. Do not invite users to send broker passwords or complete financial account statements.

Support staff see account and entitlement metadata, not private journals by default. Exceptional access is purpose-limited, time-limited, and audited. Billing refunds require authorized staff and processor reconciliation.

Actual support addresses, staffing, coverage hours, and incident contacts are founder-owned launch dependencies. No service is represented as operating before those exist.
