# ADR 0011 Explicit visual and workflow defaults

Date: October 19, 2026
Status: Engineering-selected implementation baseline

## Context

The previous sketch was rejected and profiles/social actions were under-specified.

## Decision

Use the documented neutral dark/light token system, typography/layout/component states, complete page catalog, avatar/bio/share/repost semantics and dashboard. Present real rendered flows for review.

## Consequences

Agents can build without inventing styling or omitting surfaces. Founder visual acceptance remains a release review, not a claim the palette was already approved.

## Alternatives and revisit trigger

Use [system architecture](../architecture/system-design.md), [integration contracts](../architecture/integrations.md), and [requirements](../product/requirements.md) for the detailed boundary. Revisit if supported versions, measured performance, legal/supplier terms, founder scope or release evidence invalidate the decision. Preserve the original decision and document the replacement rather than silently changing the stack.
