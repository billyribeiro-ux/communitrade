# P06 chart rendering evidence

Date: October 20, 2026. Requirements: REQ-007, REQ-028. Acceptance: AC-007 and P06 portions of AC-028. Status: implemented locally; automated checks pass. Rendered browser acceptance remains blocked and is not passed.

## Scope

Dedicated Lightweight Charts 5.2.1 client rendering, candles/volume/optional EMAs, all five intervals, normalized session-aware history and provenance, accessible text alternatives, responsive CSS-only controls and lifecycle cleanup. Options use the actual underlying stock; futures retain their dated contract. No drawing editor, chart-state writes, publication locking or export is included; those remain P07/P08.

Parallel implementation used three cheaper agents for data validation, rendering/lifecycle and API/protocol checks; root owned integration, bounded review, execution and documentation. Exact source prices remain available outside the canvas. Synthetic data remains labeled Demo data, and commercial data rights remain open. The initial P05 reference metadata and immutable migration history were preserved.

## Delivered behavior

- Dedicated browser-only ChartHost using the exact-pinned v5 `createChart` and `addSeries(CandlestickSeries/HistogramSeries/LineSeries)` APIs. Candles, separate volume scale, native crosshair, mouse/touch pan/zoom, accessible pan/zoom/fit buttons and keyboard controls are implemented. Default viewport shows the latest 120 observed candles; Fit shows the complete loaded history. Theme/EMA changes preserve a compatible viewport. Actual interactive/browser behavior remains unverified as explained below.
- Optional EMA 20/50/200 with a complete-period SMA seed and no invented warmup candles. Initial and updated canvas colors read the shared CSS tokens; Phosphor and CSS Modules supply the authored controls. Resize/theme/media observers, exact crosshair handler identity, partial initialization failures and disposal are exercised with injected resources. React remount/route cleanup is implemented, but an actual browser leak measurement is not claimed.
- Five intervals, New York default or selected display timezone, visible regular/exchange session and unadjusted labels, provider/as-of/delay/freshness/demo notices, explicit missing/unavailable/permission/error/retry states and original decimal OHLCV text tables. Canvas/indicator numeric conversion is isolated from source decimals. Exact BigInt comparisons reject inconsistent OHLC; values beyond the safe numeric canvas range preserve the text alternative instead of plotting misleading values.
- Public/member instrument detail pages use the actual API. Option references resolve their actual stock underlying; premiums/net spread values are explicitly separate. Futures use the selected dated contract and never roll automatically. Month-selection links open that actual contract's chart. Historical metadata details stay historical while their chart identifies current-context metadata. Disabling new publishing preserves permitted chart history; the separate eligibility validation still rejects new plans.
- Initial SSR supplies validated history/text prices, with a bounded source request; dynamic loading isolates the canvas and a chart error boundary preserves text prices on renderer failure. Client requests use same-origin credentials and no-store, cancel on route/interval change, bound each request, validate every page and reject overlaps, loops, source/permission changes and mismatched references. Coverage is 90 calendar days intraday or one calendar year daily, ending no later than contract expiration. Maximums are 10,000 records per page, 100 transport pages and 200,000 observations, including empty advancing supplier pages. Partial failure is not presented as complete history.
- Existing bar API now enforces regular stock versus exchange futures sessions, UTC range/horizon/cursor/page bounds, display plus retained-bar permission, explicit option-premium rejection and provider/catalog metadata agreement. Source-version disagreement fails with a safe 503 rather than being relabeled. Synthetic adapters load current canonical fixture terms, including corrected futures metadata versions, ticks, multipliers and months. Daily/hourly candles anchor at session opens; completed partial final hours, early closes, holidays, overnight trading dates and UTC-midnight bounds are covered. Synthetic calendars remain illustrative, not authoritative CME/NYSE data.

No new endpoint, chart-state write, model or SQL migration was added. Canonical/generated contracts remain **125 operations / 106 schemas**, and persistence remains **52 Prisma models / ten immutable migrations**. New dependencies are Lightweight Charts **5.2.1** and locked fancy-canvas **2.1.0**; the host addition and Docker frozen install succeeded. Upstream chart LICENSE/NOTICE and the omitted fancy-canvas MIT text are retained under `third-party/`. Native attribution and a visible TradingView link remain. No global toolchain or local secret configuration was changed.

## Defects corrected during acceptance

The existing bar page implementation capped requests at 100 despite the canonical 10,000 bound. It also mapped a stock exchange-session request to regular bars while echoing the requested session. These now match the API contract and supported asset/session policy.

Daily UTC-midnight fixture timestamps shifted the displayed date in New York; actual session-open timestamps now match production normalization. Hourly fixtures now anchor at 09:30 ET for stocks, retain completed partial final hours and respect early closes. Intraday futures holidays follow the fixture calendar's trading date. A P05 HTTP regression caught a futures hourly request ending at UTC midnight returning zero evening bars; the candidate-date boundary was fixed and the exact regression added.

The new provider/catalog version guard exposed futures fixture envelopes still reporting v1 against corrected catalog v2. Canonical fixture metadata now propagates into the adapter, and malformed/stale reference versions remain refused. Review also corrected exact decimal comparisons, safe canvas bounds, missing-page provenance, pagination capacity for a year of minute-based daily aggregation, viewport preservation, chart-only error fallback and wrapping controls at narrow widths. An intermediate typecheck observed an in-progress zoom-control edit; final checks passed after completion.

Initial failed assertions, transient development states and earlier incomplete test attempts are not counted as passes. Bounded agent/root review supplemented the executed checks; it does not establish rendered acceptance or supplier conformance.

## Browser limitation

The supported browser tool was retried for `http://localhost:3000/instruments` in this milestone. It denied access under a saved user permission/security policy and explicitly prohibited alternate browser/headless/workaround access. No workaround was attempted. Visual layout, real canvas rendering, keyboard/touch behavior, screen readers, zoom/widths and browser-matrix acceptance are unverified. Node lifecycle mocks and HTTP/SSR are not substitutes for these checks.
