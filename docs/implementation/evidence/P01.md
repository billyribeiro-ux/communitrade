## Failures found and corrected

1. The TypeScript ESLint parser excludes TS7 and Nest CLI depends on the removed compiler API. Retained all agreed pins; used direct compiler builds, explicit injection, Next CLI checking and Oxlint. Verified final builds rather than silently changing major versions.
2. pnpm 12 ignores the old `onlyBuiltDependencies` setting. Replaced it with `allowBuilds`, exact fresh-release exceptions and strict release-age handling. Frozen install passed.
3. Mac bind-mount permission handling made PostgreSQL try to execute the init script, failing with permission denied. Copied it non-executable into the PostgreSQL image. Recovered the existing local volume by creating missing roles/databases; separately verified fresh-volume initialization. No records/volumes were deleted.
4. Prisma tooling needed OpenSSL in the slim Node image. Added the libraries inside the container image. Host tooling was unchanged.
5. Nested shell quoting broke the original Keycloak health probe. Switched to exec-form Bash; an actual in-container management request returned HTTP 200 and Docker now reports healthy. Discovery also passed over the host port.
6. A production build invoked from a development container inherited `NODE_ENV=development` and failed prerendering. Added a cross-platform Node build launcher that sets production mode for Next. The final full Linux build passed without that error.
