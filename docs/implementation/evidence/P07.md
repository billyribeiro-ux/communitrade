# P07 private drawing editor evidence

Date: October 20, 2026. Requirements: REQ-008, REQ-009, REQ-028. Acceptance: AC-008 and drawing/autosave portions of AC-009 and AC-028. Status: implemented locally; automated checks pass. Actual rendered browser/touch acceptance is blocked and is not passed.

## Scope and behavior

P07 adds owned chart drafts at `/app/drafts`, `/app/publish` (private chart setup) and `/app/drafts/{id}`. Stocks and options use an actual stock reference; futures use a dated listed contract. Full trade terms, publication, frozen image capture and public sharing remain P08. Streaming/rooms, scanners, broker connections and payouts remain outside this milestone.

Three cheaper parallel agents implemented drawing/controller/forms, canvas/interaction, and API/persistence. Root integrated the editor, autosave, routes, review and verification. Authored styling remains CSS Modules/plain CSS with shared tokens and Phosphor icons. No dependency or global toolchain change was needed.

- All eight contract variants: horizontal line, trendline, rectangle, arrow, plain text, entry, target and invalidation overlays. Object selection, hit testing, anchor/body movement, resize through handles/form anchors, delete, cancel, bounded styles, one-gesture undo/redo and branching are implemented. The accessible object list and explicit UTC/decimal edit/create forms provide alternatives to canvas input. Mobile creation is horizontal/text; existing objects remain editable. Maximum 50 objects, unique IDs and linked fields, bounded text/styles, semantic UTC anchors and decimal strings are checked.
- v5 native canvas primitive rendering retains TradingView attribution. Missing-session/future timestamps project semantically without adding candles. Resize/theme/interval changes retain authored anchors. Rendering, pointer capture, input exclusions, keyboard shortcuts, disposal and subscription behavior have focused injected-resource tests; these do not establish physical-device/browser behavior.
- Draft creation is idempotent, setup retry preserves its created identity, and owned list/detail/chart endpoints authorize server-side. Chart initialization uses revision zero, then strong quoted ETags/If-Match, row locks and atomic chart/draft updates. Stale writes fail with 409. Current member display/retained-bar rights from both effective database grants and the independently configured provider, plus matching current reference metadata, gate writes; the owner can still read saved authored values when current rights change.
- Entry/target/invalidation drawings synchronize `underlyingChartLevels` atomically. Option premium/spread `entryPrice` and `priceKind` remain separate. Chart notes/thesis may become public at publication; journal-only fields are excluded by the chart schema and are never accepted as chart payloads. No broker verification is implied. Stored provenance describes its selected provider; it is not a cryptographic assertion of a particular provider fetch or independent trade verification.
- Autosave serializes writes, retains newer local edits while a request is in flight, and saves committed gestures rather than intermediate drag positions. Visible pending/saving/error/conflict status, retry, unload warning and explicit discard/reload recovery are implemented. An uncertain acknowledgement cannot silently overwrite a newer chart. No draft data is written into localStorage or public caches.
- Saved view state includes interval, timezone, UTC viewport, EMA periods/colors, drawings and source provenance. History loading keeps existing bounds/cancellation/validation and explicit errors. Metadata mismatch blocks editing rather than silently relabeling saved prices. Source failure preserves authored drawing/text alternatives.

No SQL migration, Prisma model, canonical operation/schema or runtime dependency was added. Inventory remains 52 models, ten immutable migrations and 125 operations / 106 schemas. Four insert-only owned local fixtures provide stock/options/futures and another owner's records; repeat seeding must preserve edits. Non-empty draft attachments are explicitly rejected until the P08 attachment lifecycle exists.

## Browser gate

P07 attempted supported in-app browser navigation to `http://localhost:3000/app/drafts`. The tool rejected the action: a saved user permission or managed policy denied origin access. No alternate browser, headless browser, raw CDP or indirect workaround was used. Actual canvas screenshots, touch/320px interaction, browser reload/stale-tab interaction, screen-reader behavior, visual design and browser performance remain unverified. HTTP/SSR, Node tests and database checks are separate evidence and do not pass those browser requirements.
