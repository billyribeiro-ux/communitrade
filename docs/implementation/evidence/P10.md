# P10 — Private research workspace evidence

Date: October 20, 2026. Requirements: REQ-018, REQ-019 and the journal export portion of REQ-023; acceptance AC-018, AC-019, AC-023. Local implementation and automated/live HTTP acceptance are complete. Rendered browser acceptance remains blocked and is not marked passed. Notifications remain P11, billing lifecycle P12, broader privacy archive/deletion P13, and release integration P14.

## Delivered behavior

- Owner-only stand-alone and linked journals: private thesis/notes/tags/reviews, search and filters, precise owner/filter-bound pagination, optimistic edits and deletion. Ordinary administrators receive the same private-object 404 as another member. Linked public source visibility/data rights are checked again without hiding the owner's notes when the source is unavailable.
- Supported private stock, all six option strategies and futures positions use the existing reference hydrator, lifecycle and exact decimal calculator. Another author's linked trade receives an independent private position; one's own public position can be linked read-only. Private corrections append visible superseding events, retain the original, preserve frozen risk, and support safe idempotent retries. Public performance queries exclude private positions.
- Free basic counts/individual outcomes and Pro period/strategy/tag/asset analysis. Distributions, mean R, realized results, incomplete-cost/retrospective exclusions and review completion expose their denominators. Expired entered options project unresolved consistently in UI analysis and CSV rather than implying execution. Paid fields remain null on Free; advanced requests fail explicitly without current entitlement.
- Atomic UTC-month creation allowances of 30/1,000, watchlists 1/10 with 25/100 instruments, and chart layouts 1/10. Existing oversized records survive downgrade and remain readable/editable/removable/raw-exportable. Collection additions serialize in transactions; persisted arbitrary limits JSON cannot raise product allowances. Dedicated synthetic quota and downgrade fixtures are insert-only for authored records.
- Watchlist management uses stable IDs and batched, current-member-display-authorized catalog labels, with no quote fetch or per-item browser request fan-out. Private chart templates save/apply/update through the chart editor with compatible instrument/version checks and current revisions; published/processing charts cannot accept a template.
- Raw personal CSV and Pro filtered analytical jobs: transactional outbox, pg-boss dispatch, status/failure/retry, immutable attempt objects, stale-claim fencing, entitlement checks before processing/finalization/download, and owner-authenticated no-store downloads expiring within 24 hours. Formula-leading cells are neutralized after whitespace/control characters. Raw CSV includes stored journal, owned position, leg, event (including superseded) and snapshot rows. Output over 50 MiB fails visibly instead of truncating. Failed expiry deletion retains its reference for retry. Personal archive/deletion remains explicitly unavailable until P13.

Member routes: `/app/journal`, `/app/journal/new`, `/app/journal/{id}`, `/app/journal/analytics`, `/app/watchlists`, `/app/layouts`. Export request/status/download is inside Journal; analytical exports use the last successfully applied analysis filters. Dashboard and public-idea shortcuts connect these workflows. Styling is plain CSS/CSS Modules using shared tokens and Phosphor.

## Persistence and contracts

55 Prisma models; seventeen ordered migrations. Additive 015 adds private journal fields, active owner/source uniqueness, update clocks and bounds; 016 adds durable export fields/status/expiry/claim constraints; 017 permits immutable attempt-specific private storage keys. Applied SQL remains unchanged. Generated OpenAPI/runtime/client contracts have 134 operations and 115 named schemas. Added reads are getWorkspaceUsage/getWatchlist/getLayout/listExports; correctPrivatePositionEvent appends an owner-private superseding report. JournalAnalytics and ExportJob/Page are explicit DTOs, and Watchlist optionally contains currently authorized Instrument summaries. ADR inventory is 21; see [ADR 0021](../../adr/0021-private-workspace-and-export-jobs.md).

The worker adds only the existing @trading/domain workspace dependency for shared decimal/ratio formatting. No external pinned runtime version or host-managed tool was changed. No new third-party license was introduced.
