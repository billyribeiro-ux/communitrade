## Scope

Three reused cheaper parallel agents implemented publication/API/persistence, lifecycle/corrections/calculation projections, and trusted capture/worker. Root integrated the CSS-only composer, attachment/review/recovery UX, public/version pages, owner reporting, performance panels, correction author/staff forms, image authorization, containers/contracts and documentation. No Tailwind or global host tool installation was introduced. No P09 community/streaming/scanners/broker/payout work, deployment, purchase, Git commit/PR or remote CI result is claimed.

- Full private composer supports stock long/short, all six standard option structures, actual dated ES/MES/NQ/MNQ contracts and educational content. It collects thesis, actual contract IDs/units, entry window/conditions, intended exits/conflicts, separately linked underlying drawings, processed attachments and an explicit review. Decimal-safe planning estimates are revalidated on the server. Reloading can recover an in-flight publication job; published drafts are locked and linked to public evidence.
- Publication freezes an immutable owner-only candidate and returns 202. A pinned trusted worker renders licensed frozen bars/drawings with Lightweight Charts, source/reporting/attribution notices and no selection handles, validates dimensions, converts WebP and stores immutable version-bound bytes/checksum. Only final successful processing advances public visibility/time and creates the position. Client chart-image injection is rejected. Failed candidates/drafts and previous correction versions remain preserved.
- Public detail shows exact terms/drawings, frozen image/source/version, original and correction history, reported lifecycle and separately requested current market context. Pending/failed replacement branches cannot be read as public history. Images require current source authorization; attachments additionally require membership in a committed visible version. Owner access does not bypass chart-source rights.
- Reported entry/partial/final/cancel/never-entered/exception/resolution/review events use owner authorization, optimistic revision, replay-safe keys and immutable claimed/received clocks. Actual entry fills drive cash accounting; original planned risk/version remains frozen. Missing fees and short-stock borrowing costs remain unknown. Late valid entries are retrospective. Resolution net applies only to unresolved remaining units; partial proceeds/costs are combined once and exact R recomputed. Expiry never invents a fill.
- Text corrections append a visible reasoned version; structured changes require independent staff review and recent MFA. Changed chart/terms retain the existing public evidence while trusted recapture completes. Corrected reports supersede visibly and recalculate with source-version/event-cutoff provenance; originals remain inspectable. Public performance discloses its eligible complete-cost denominator, breakevens, cost coverage, retrospective/open/unresolved exclusions and reported cash/R. Editorial eligibility is completeness/follow-up transparency, with no paid or high-win-rate promotion.
