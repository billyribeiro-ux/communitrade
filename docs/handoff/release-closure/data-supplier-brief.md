# Market-data approval brief — draft for founder/vendor review

This brief has not been sent and is not a license agreement. Business/operator/domain and supplier account remain founder inputs.

The Phase 1 product is a US adult trading-research community with Free and paid Pro membership. Members publish their own stock, option and futures ideas, chart drawings, commentary and member-reported lifecycle/results. Launch covers listed stocks, six supported option structures (long call/put and four debit/credit verticals), and dated ES/MES/NQ/MNQ futures. Charts show the option underlying; historical option-premium candles are outside this baseline. There is no execution, broker linkage, automated copying, scanner, livestream, creator payout or claimed broker verification.

Please provide written dataset/venue coverage and prices for the actual use, including each independent permission:

| Use | Required written scope |
| --- | --- |
| Public and member display | Anonymous web visitors, authenticated Free and paid Pro; delayed quote/bar freshness labels; professional/nonprofessional classification and applicable fees/reporting. |
| Reference and calendar retention | Actual symbol/contract IDs, expiry/strike/right/multiplier/tick versions, corrections, corporate actions and authoritative venue/session/holiday calendars. |
| Bar retention | Supported intraday/daily intervals and server retention needed for drawing replay, publication evidence and chart readback. |
| Frozen images | Persisted original charts, thumbnails, historical versions and drawings; attribution and permitted lifespan after an agreement expires or rights change. |
| External sharing | Watermarked/attributed exported images and network previews on external platforms; text-only fallback when image rights are absent. |
| Personal exports | Private raw journal/analytical CSV/JSON and any licensed data fields included; rights differ from public redistribution. |
| Operations | Approved as-of/delay values, ingestion limits, public audience limits, staging/beta terms, real conformance samples, error/outage behavior and escalation. |
| Revocation | What must stop immediately and what historical records/images may remain; required purge/reporting terms and notices. |

The local representative test used 5,000 synthetic accounts, 1,000 monthly-active proxies and 100 concurrent requests, with 50,000 publications/250,000 comments. These are capacity-planning assumptions, not actual members or 100 independent live feeds. Ask for development, invited-beta and public-production commercial terms separately. An API key alone does not establish any redistribution/retention permission.

Record the agreement identifier, effective/expiry dates, datasets/audiences/purposes, delay, attribution, approved reference/schema/calendar mapping, costs and accountable reviewer. Hold the signed document privately; commit only a redacted approval/digest reference. Engineering imports grants only after that evidence exists.
